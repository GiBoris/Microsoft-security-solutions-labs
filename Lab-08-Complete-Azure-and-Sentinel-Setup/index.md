# Lab 08 — Complete Azure & Sentinel Setup

This lab demonstrates an end-to-end deployment of a Microsoft cloud security monitoring environment using Azure, Microsoft Defender, Log Analytics, and Microsoft Sentinel.

---

## Lab Scope

- Azure resource group, virtual network, and NSG configuration;
- Windows and Ubuntu virtual machine deployment;
- Log Analytics Workspace and Data Collection Rules;
- Azure Activity, NSG, Windows, Linux, and Entra ID log ingestion;
- Defender for Cloud and Defender for Endpoint onboarding;
- Microsoft Sentinel deployment and connector configuration;
- KQL investigations;
- Analytics rules and alert validation;
- Sentinel workbook creation.
